# 更新日志

## v0.2.2

- 优化移动端流式输出的流畅度：
  - 流式 Markdown 的更新间隔上限从 2000ms 压到 120ms，文字不再成块跳出来
  - 流式期间跳过 Prism 语法高亮，回答结束后再高亮一次
  - 流式期间 Mermaid 重绘间隔从 100ms 放宽到 500ms
  - 对话状态刷新从每帧一次（≈60fps）降到 60ms 一次，减少主线程占用
  - 移动端关闭「正在思考」标题的文字流光动画

## v0.2.1

- 图标统一换成自制 **"DS" 字母标**（白底 + 品牌蓝字样），应用图标与首屏标识同款
- 移除全部 DeepSeek 图形素材，商标风险清零；图标由 `scripts/make-icons.py` 生成，可随时重绘
- 签名密钥改为存放在仓库外（`..\ds-chat-keys\`），构建工具链移到 `..\build-toolchain\`

## v0.2.0

- 项目改名为 **DS Chat**（原 DeepSeekChat），避免与官方混淆
- Android 包名由 `com.deepseek.chatdemo` 改为 `com.example.dschat`
  - 副作用：这是一个新应用，与旧包并存，需要手动卸载旧版；API Key 需重新填写
- 应用名、界面标题由「API 使用 demo」改为「DS Chat」
- 构建脚本输出改为 `dist\DSChat.apk`，密钥环境变量改为 `DSCHAT_KEYSTORE`

## v0.1.3

- 图标与首屏鲸鱼换成扁平版，去掉白色描边；鲸鱼腹部改为镂空（深色模式下不再发白）
- 移动端侧边栏改为跟手拖拽抽屉：从左边缘右划展开、内容面板同步右移并带阴影，松手过半吸附
- 竖向滑动会先判定方向，不会被抽屉手势吃掉

## v0.1.2

- 状态栏、导航栏、窗口背景跟随页面主题色，修复深色模式下顶部的白边
- 默认主题改为浅色

## v0.1.1

- 首屏增加鲸鱼标识，问候语改为「你好，让我们开始聊天吧」
- 「深度思考 / 智能搜索」开关始终显示文字标签
- 修复 assets 路径反斜杠导致的白屏
- 编译目标降到 Chrome 61，补充旧版 WebView 的运行时 polyfill
- 加入屏幕诊断面板与 console 日志

## v0.1.0

- 首次发布：WebView 外壳 + 官方 chat-demo 前端，直接调用 DeepSeek API
